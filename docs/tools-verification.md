## 修正与边界

- 原生编辑框在通过浏览器自动化直接填入 30,001 行时明显延迟。导入与粘贴现在先校验，不将超限数据放进编辑框；核心对比函数仍独立校验上限。
- 初版取消后新建 Worker 会重新请求脚本，断网时失败。现在预热时保存编译后的独立 Worker 脚本为本地 Blob，取消后可直接本地重建，断网回归通过。
- “离线”指工具与处理线程加载完成后可断网继续使用。首版不包含站点离线缓存，未保证断网首次打开或重新访问。
- 浏览器验收是桌面 Chrome 与移动尺寸 Chromium，不代表真实 iOS Safari / Android 真机验收；未作无限大小文件或跨设备性能保证。
- 本次通过结论限于新增核心及浏览器用例。旧 `tests/blog.spec.ts` 仍含改版前导航、实验页面和组件结构的断言，本轮未执行或改写该历史套件。

## 追加图片格式转换

- 引擎为固定版本 `@imagemagick/magick-wasm@0.0.45`；pnpm 已实际使用 12.14.0 并更新锁文件。保持纯静态导出，WASM 15,425,791 字节，仅转换页启动时请求；目录页未下载引擎的行为已由浏览器断言。
- 原 22 项浏览器检查与新增转换 8 项合并执行，桌面 Chrome / 手机尺寸 Chromium 共 30 项通过。新增检查覆盖实际格式列表、原尺寸 2200×1200 输出、JPEG/WebP/TIFF/BMP/ICO/AVIF/JPEG XL 输出 MIME 和文件名、可解码缩略图、真实下载、损坏文件不影响 SVG、清空，以及断网取消后再转换真实 HEIC / HEIF。修正图片保真后再次执行转换页的 8 项检查。
- 实际引擎验证 23 种可读、20 种可写，全部 20 种完成编码再解码校验；HEIC、HEIF、SVG 仅输入。真实 HEIC / HEIF 样本来源记录在 `tests/fixtures/images/SOURCES.md`。
- 独立审查复现了 GIF 首帧偏移丢失逻辑画布、ICC 配置直接移除导致颜色变化。已补上先失败再通过的测试：GIF 保留画布及像素位置，超大逻辑画布解码前拒绝；带 Display P3 ICC 的像素实际转换为 sRGB 后才移除配置。现有核心测试共 41 项通过。
- Webpack 将引擎拆为共享脚本，初次断网取消测试明确失败。预热现在同时缓存脚本依赖与 WASM，通过本地 Blob 重建，修复后断网回归通过。离开页面时释放脚本、输出和缩略图 Blob。
- 输出为 8 位静态图片，首帧/首页，不保留图层、EXIF 或 HDR 原始动态范围；ICO 限 256px 并补正方形，JPEG/BMP 白底。20 张 / 单张 20 MiB / 2400 万像素，单张转换 60 秒限时。非无限格式、非原生高位深编辑器。
