# 文字游乐场预览

用户已确认：先在独立预览页实现“玻璃扭曲 → 点击散落 → 拖拽字母 → 归位”的完整交互，体验后再决定是否替换首页粒子标题。

- 路径：`/playground/text/`，沿用站点字体、主题和调色板。
- 默认展示两行 `Code. Create.`；指针附近呈现玻璃透镜式变形。
- 按用户补充的参考图，透镜同时呈现渐变色散边缘和轻微高光。彩边跟随指针，离开后恢复原色；深浅主题都必须可见。
- 点击标题或操作按钮后，字母掉落、碰撞，并可拖动和甩出；运动始终限制在舞台内。
- “重新排好”将字母动画送回原位；停止操作九秒后自动归位，拖拽期间不归位。
- 手机保留点击和字母拖拽，空白区域仍可正常上下滚动。
- 使用 OGL 和 Matter.js；本功能不引入 Three.js。物理库按需加载，两种效果按阶段运行。
- 离屏、后台暂停；尊重系统减少动态效果；WebGL 不可用时保留可读标题与物理玩法。
- 预览页不加入主导航和 sitemap，不替换首页，不提交或推送代码。

## Approaches

1. 两个独立展示区域：易于分别比较，但交互重复占据页面空间。
2. 同一标题连续切换：用户已选择此方向；复用排版与坐标，以单一入口体验两种效果。
